### 3.3 关键发现

- **触觉类 benchmark 和动作类 benchmark 互斥**：AnyTouch TAG/OF1/OF2/Feel（AnyTouch 自带的 probe benchmark）评测触觉表征质量，LIBERO/RoboTwin/ManiSkill 评测操作成功率。接口抽象应该屏蔽**调用差异**而非强行统一评测任务。
- **大多数 WAM/VLA 模型兼容 LIBERO**：这是最通用的仿真操作 benchmark，优先对齐。
- **触觉接口有两类使用场景**：
  - **Linear Probe 评测**：冻住编码器，训练分类头 → 衡量表征质量（AnyTouch 方式）
  - **端到端策略评测**：直接输出动作 → 衡量操作能力（LIBERO 方式）

## 四、接口抽象设计

### 4.1 统一接口定义

```python
# ---- 模型侧 ----

class ModelAdapter(ABC):
    """任何模型只需实现此接口即可接入所有兼容 Benchmark"""

    def load(self, checkpoint_path: str, config: dict) -> None
    def act(self, observation: dict, task_info: dict = None) -> np.ndarray
    def reset(self) -> None
    def encode(self, tactile_input: torch.Tensor) -> torch.Tensor  # 触觉模型专用

# ---- Benchmark 侧 ----

class BenchmarkRunner(ABC):
    """任何 Benchmark 只需实现此接口即可评测所有兼容模型"""

    def setup(self, config: dict) -> None
    def evaluate(self, model: ModelAdapter, **kwargs) -> dict  # → {metrics}
```

### 4.2 接口需要处理的两种模式

```
动作模型接口：  model.act(obs: dict) → action: np.ndarray     # 适合 LIBERO/RoboTwin/DROID
触觉模型接口：  model.encode(tactile_img) → feature: Tensor    # 适合 AnyTouch probe eval
```

## 五、优先实施路线（以 benchmark 为中心）

**目标：让所有 baseline 都能跑以下 5 个 benchmark。** 按接入价值排序：

| 优先级 | Benchmark | 类型 | 能跑的 baseline | 部署成本 | 选它的理由 |
|--------|-----------|------|----------------|---------|-----------|
| **P0** | **LIBERO** | 操作仿真 | 几乎全部动作模型 | ✅ low (32G, conda 就绪) | 覆盖面最广，接口设计的最佳起点 |
| **P0** | **AnyTouch TAG/OF1/OF2/Feel** | 触觉 probe | 全部触觉模型 | ✅ low (198G, Docker 就绪) | 接口最简单（encode → probe），触觉评测刚需 |
| **P1** | **RoboTwin 2.0** | 操作仿真 | Motus/FastWAM/OpenPi | ⚠️ mid (待下载) | 50 任务，场景更丰富 |
| **P1** | **ManiFeel** | 触觉操作仿真 | OpenPi/RDP/DP/VLA-Touch | ⚠️ mid (14G, 需 IsaacGym) | 触觉→操作闭环评测 |
| **P2** | **UniVTAC** | 触觉仿真 | Motus/DreamZero/OpenPi/RDP/DP/VLA-Touch | 🔴 high (6.1G, 需 Isaac Lab) | 最完整的触觉仿真套件，但环境依赖最重 |

### 实施策略

> **两条线并行**，互不阻塞：
> 
> **① 动作线（LIBERO → RoboTwin 2.0 → UniVTAC）** — `model.act(obs) → action` 接口
> 
> **② 触觉线（AnyTouch → ManiFeel）** — `model.encode(tactile) → feature` 接口
>
> 先调通 P0 的两个 benchmark（LIBERO + AnyTouch），验证接口抽象覆盖两种模式，再扩展到 P1/P2。
